# 🏡 Family Go!

**대를 잇는 인생 시뮬레이션.** 한 명의 캐릭터에서 시작해 사랑, 결혼, 자녀, 직업, 은퇴까지
인생의 모든 순간을 선택하고, 마을을 키우며, 여러 세대에 걸친 가족의 유산을 만들어가는 웹 게임입니다.

빌드 도구도 외부 라이브러리도 없습니다. 브라우저와 Node.js만 있으면 됩니다.

## 실행하기

```bash
npm start          # http://localhost:5173 에서 플레이
npm test           # 게임 규칙 테스트 (49개)
```

> ES 모듈을 쓰기 때문에 `index.html` 을 파일로 직접 열면 동작하지 않습니다.
> 서버 없이 즐기려면 `npm run build` 로 만든 `dist/play.html` 한 파일을 열면 됩니다.

## 이렇게 즐깁니다

1. **성·이름·성별·타고난 성격·마을 이름**을 정하고 18세로 시작합니다.
2. 매년 **한 가지 활동**(공부/운동/예술/사교/일/가족/휴식)을 고르고 `한 해를 보낸다` 를 누릅니다.
3. 해마다 **인생 이벤트**가 찾아옵니다. 선택에 따라 능력치·재산·가족의 마음이 달라집니다.
4. **인연** 탭에서 사람을 만나 데이트하고, 호감도 70을 넘기면 청혼할 수 있습니다.
5. **직업** 탭에서 학력과 능력치에 맞는 일을 구하고, `일에 집중` 으로 승진합니다.
6. **마을** 탭에서 집·텃밭·학교·도서관·극장을 짓습니다. 건물은 가족 전체를 성장시킵니다.
7. 아이가 성인이 되면 **유산** 탭에서 스스로 대를 넘기거나, 주인공이 세상을 떠나면 자손이 이야기를 잇습니다.

## 게임의 심장: 유전

아이는 부모에게서 **외모 · 능력 · 성격**을 물려받습니다.

| 물려받는 것 | 방식 |
|---|---|
| 외모 (피부·머리색·머리모양·눈동자·얼굴형·주근깨) | 유전자마다 부모 중 한쪽에서 상속, 8% 확률로 돌연변이 |
| 능력 잠재력 | 부모 평균 ±10, 실제 능력치는 아기답게 낮게 시작해 자라며 잠재력에 수렴 |
| 성격·재능 | 부모의 특성 중 최대 2개 + 새로 나타나는 기질 (희귀 특성은 6%) |

화면의 얼굴은 이 유전자를 그대로 그린 SVG라, **아이가 누구를 닮았는지 눈으로 보입니다.**
나이가 들면 머리가 하얘지고, 지능이 높으면 안경을 쓰고, 행복하면 웃습니다.

## 구조

```
index.html            화면 껍데기
assets/style.css      따뜻한 톤의 스타일 (다크 모드 지원)
server.mjs            의존성 없는 정적 서버
build.mjs             한 파일짜리 dist/play.html 생성기
src/
  core/
    rng.js            시드 기반 결정론적 난수 (저장/복원 가능)
    util.js           공용 상수와 도우미
    genetics.js       외모·능력·성격 유전
    person.js         인물 생성, 나이 먹기, 학력, 수명
    economy.js        연봉·생활비·승진
    village.js        건물 효과, 마을 등급, 관리비
    game.js           게임 상태와 흐름 (한 해 보내기, 이벤트, 결혼, 출산, 계승)
    save.js           localStorage 저장 / JSON 내보내기
  data/
    names.js  traits.js  jobs.js  buildings.js  events.js
  ui/
    avatar.js         유전자로 얼굴 SVG 그리기
    views.js          화면 조각 (문자열 HTML)
    app.js            상태 + 클릭 위임
tests/                node:test 기반 규칙 테스트
```

핵심 규칙(`src/core`)은 DOM을 전혀 모릅니다. 그래서 테스트에서 수백 년치 인생을 그냥 돌려볼 수 있습니다.

## 균형 잡힌 숫자들 (조정 지점)

| 값 | 위치 | 기본값 |
|---|---|---|
| 성인 1인 연간 생활비 | `src/core/economy.js` | 1,200만원 |
| 아이 1인 추가 비용 | `src/core/economy.js` | 600만원 |
| 호봉 상한 | `src/core/economy.js` | 10 |
| 건물 1레벨당 연 관리비 | `src/core/village.js` | 110만원 |
| 결혼 비용 / 출산 준비금 | `src/core/game.js` | 1,500 / 400만원 |
| 상속률 (사망 / 자발적 계승) | `src/core/game.js` | 70% / 90% |
| 돌연변이 확률 | `src/core/genetics.js` | 8% |

## 콘텐츠 추가하기

- **이벤트**: `src/data/events.js` 에 객체 하나를 더합니다. `check` 를 주면 능력치 판정 이벤트가 됩니다.
- **직업**: `src/data/jobs.js` 에 학력(`edu`)과 요구 능력치(`req`)를 적습니다.
- **건물**: `src/data/buildings.js` 에 `effect(level)` 이 돌려주는 보너스를 정의합니다.
- **성격**: `src/data/traits.js` 에 추가하면 그 즉시 유전 대상이 됩니다.

새 콘텐츠를 넣은 뒤에는 `npm test` 로 규칙이 깨지지 않았는지 확인하세요.

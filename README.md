# 한국사 연표 스프린트

고1 한국사 기말고사 대비 암기 앱. 단일 HTML 파일이며 외부 의존성은 Google Fonts뿐이다.

## 출제 범위

2022 개정 한국사2 **Ⅰ단원 「일제 식민 통치와 민족 운동」** 01~03-1(교과서 8~33쪽)을
소단원 단위로 옮겼다. 기본으로 켜져 있는 8개 단원이 이 범위다.

| id | 소단원 | 교과서 |
|---|---|---|
| `s1` | 20세기 전반의 세계 | 01-1 · 10~11쪽 |
| `s2` | 무단 통치와 수탈 체제의 확립 | 01-2 · 12~13쪽 |
| `s3` | 민족 분열 통치와 경제 수탈 | 01-3 · 14~15쪽 |
| `s4` | 민족 말살 통치와 전시 동원 체제 | 01-4 · 16~19쪽 |
| `s5` | 1910년대 국내외 독립운동 | 02-1 · 20~21쪽 |
| `s6` | 3·1 운동의 전개와 의의 | 02-2 · 22~25쪽 |
| `s7` | 대한민국 임시 정부의 수립과 활동 | 02-3 · 26~29쪽 |
| `s8` | 무장 독립 전쟁 | 03-1 · 30~33쪽 |

`x0` 전근대 · `x1` 개항기 · `x2` 일제강점기(범위 밖) · `x3` 현대는 기본으로 꺼져 있고
`나` 탭에서 켤 수 있다.

## 문제 유형

연표 사실 하나에서 4가지 문제를 자동 생성한다. 오답 선택지는 **같은 단원**에서만
뽑으므로 소거법으로 찍기 어렵다.

- `flash` 플래시카드 (자기 채점 3단계)
- `year` 사건 → 연도
- `event` 설명 → 사건명
- `cloze` 설명 속 핵심어 빈칸
- `order` 연표 정렬 — 4장을 순서대로 (5문제마다 삽입). 연도가 4개 이상 서로 다른
  단원에서만 출제한다 — 3·1 운동처럼 한 해에 몰린 단원은 순서를 물을 수 없다.
- `ox` O·X 함정 (직접 작성)

## 간격 반복 (라이트너)

`BOX_DAYS = [0, 1, 3, 7, 16]`

정답이면 상자를 한 칸 올려 그만큼 뒤에 다시 출제하고, 오답이면 상자를 0으로
되돌려 같은 날 다시 낸다. 진도는 `localStorage`(`hansa-sprint-v2`)에 저장된다.

## 탭

`오늘`(복습 큐) · `연표`(정렬 게임 + 전체 연표) · `퀴즈`(무한 랜덤) ·
`치트키`(두문자 + 비교표) · `나`(통계 · 오답 노트 · 범위 · D-day)

## 개발

빌드 과정이 없다. `index.html`을 브라우저로 열면 된다.
데이터를 고치려면 `RAW` / `OXRAW` / `COMPARE` / `MNEMO` 배열을 편집한다.
`cloze` 문제가 나오려면 설명(`d`) 안에 빈칸 키워드(`k`)가 그대로 들어 있어야 한다.

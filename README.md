# 한국사 연표 스프린트

고1 한국사 기말고사 대비 암기 앱. 단일 HTML 파일이며 외부 의존성은 Google Fonts뿐이다.

## 학습 데이터

| 종류 | 개수 | 내용 |
|---|---|---|
| 연표 사실 | 162 | 단원 · 연도 · 사건명 · 설명 · 빈칸 키워드 |
| O·X 함정 | 43 | 시험에서 실제로 헷갈리는 지점 + 해설 |
| 비교표 | 14 | 갑신정변/갑오개혁, 을사늑약/정미7조약 등 |
| 두문자 암기법 | 16 | 순서·흐름을 한 줄로 압축 |

단원 구분: `u0` 전근대 · `u1` 개항기 · `u2` 일제강점기 · `u3` 현대.
기본 시험 범위는 2학기에 맞춰 `u1·u2·u3`으로 켜져 있다.

## 문제 유형

연표 사실 하나에서 4가지 문제를 자동 생성한다. 오답 선택지는 **같은 단원**에서만
뽑으므로 소거법으로 찍기 어렵다.

- `flash` 플래시카드 (자기 채점 3단계)
- `year` 사건 → 연도
- `event` 설명 → 사건명
- `cloze` 설명 속 핵심어 빈칸
- `order` 연표 정렬 — 4장을 순서대로 (5문제마다 삽입)
- `ox` O·X 함정 (직접 작성)

## 간격 반복 (라이트너)

`BOX_DAYS = [0, 1, 3, 7, 16]`

정답이면 상자를 한 칸 올려 그만큼 뒤에 다시 출제하고, 오답이면 상자를 0으로
되돌려 같은 날 다시 낸다. 진도는 `localStorage`(`hansa-sprint-v1`)에 저장된다.

## 탭

`오늘`(복습 큐) · `연표`(정렬 게임 + 전체 연표) · `퀴즈`(무한 랜덤) ·
`치트키`(두문자 + 비교표) · `나`(통계 · 오답 노트 · 범위 · D-day)

## 개발

빌드 과정이 없다. `index.html`을 브라우저로 열면 된다.
데이터를 고치려면 `RAW` / `OXRAW` / `COMPARE` / `MNEMO` 배열을 편집한다.
`cloze` 문제가 나오려면 설명(`d`) 안에 빈칸 키워드(`k`)가 그대로 들어 있어야 한다.

# 🏡 Family Go!

**대를 잇는 인생 시뮬레이션.** 한 명의 캐릭터에서 시작해 사랑, 결혼, 자녀, 직업, 은퇴까지
인생의 모든 순간을 선택하고, 마을을 키우며, 여러 세대에 걸친 가족의 유산을 만들어가는 웹 게임입니다.

빌드 도구도 외부 라이브러리도 없습니다. 브라우저와 Node.js만 있으면 됩니다.

## 실행하기

```bash
npm start          # http://localhost:5173 에서 플레이
npm test           # 게임 규칙 테스트 (67개)
npm run build      # 서버 없이 열리는 dist/play.html 한 파일 생성
```

> ES 모듈을 쓰기 때문에 `index.html` 을 파일로 직접 열면 동작하지 않습니다.
> 서버 없이 즐기려면 `npm run build` 로 만든 `dist/play.html` 한 파일을 열면 됩니다.

## 이렇게 즐깁니다

1. **출신 가문**을 고릅니다. 여기서 판이 갈립니다 — 몰락한 명문가는 4,000만원 빚과 함께,
   홀로 남은 아이는 300만원으로, 상인 집안은 6,000만원과 낮은 행복으로 시작합니다.
   성·이름·성별·타고난 성격·마을 이름을 정하고 18세로 출발합니다.
2. 매년 **한 가지 활동**을 고르고 `한 해를 보낸다` 를 누릅니다. 활동 11가지 중 셋은 위험합니다 —
   🔥 극한 훈련(다칠 수 있음), 🛵 부업(몸과 마음이 지침), 🎲 한탕 노리기(자금의 15%를 걺).
   또는 **`▶ 자동으로 흘려보내기`** 를 켜두면 손을 대지 않아도 해가 흐릅니다.
   그동안 가족들이 일해서 돈을 벌고, 사건이 생기면 저절로 멈추고 화면에 뜹니다.
3. 해마다 **인생 이벤트**가 찾아옵니다. 선택에 따라 능력치·재산·가족의 마음이 달라집니다.
4. **인연** 탭에서 사람을 만나 데이트하고, 호감도 70을 넘기면 청혼할 수 있습니다.
5. **직업** 탭에서 학력과 능력치에 맞는 일을 구하고, `일에 집중` 으로 승진합니다.
6. **마을** 탭에서 집·텃밭·학교·도서관·극장을 짓습니다. 건물은 가족 전체를 성장시킵니다.
7. **업적**을 달성할 때마다 보상 카드 3장이 열립니다. 하나를 고를 때까지 시간은 멈춥니다.
8. 아이가 성인이 되면 **유산** 탭에서 스스로 대를 넘기거나, 주인공이 세상을 떠나면 자손이 이야기를 잇습니다.

## 긴장을 만드는 세 가지

**⚠️ 위기** — 몇 년에 한 번, 가문을 흔드는 일이 벌어집니다. 빚더미, 큰 병, 마을 재난,
집을 나간 가족, 소송. 각각 **기한**이 있고, 기한을 넘기면 실제로 잃습니다 —
건물이 넘어가고, 재산이 반토막 나고, 떠난 가족은 돌아오지 않습니다.
돈으로 막거나(부분 상환도 됩니다) 능력치로 직접 부딪힐 수 있습니다.
위기의 규모는 지금 형편에 맞춰 커지므로, 부자가 되어도 만만하지 않습니다.

**⭐ 꿈** — 모든 가족이 아홉 살 무렵 **자기 꿈**을 하나 품습니다. 의사 되기, 무대에 서기,
아이 셋 키우기, 아흔까지 살기… 이루면 큰 보상과 함께 축하 화면이 뜨고,
못 이룬 채 떠나면 그 이름이 유산 화면에 남습니다. 족보에서 각자의 꿈을 볼 수 있습니다.

**🏆 가문의 숙원** — 한 시대(25~35년) 안에 이뤄야 할 큰 목표가 항상 하나 걸려 있습니다.
마을 등급 4 달성, 자금 40,000만원, 가족 8명, 명성 45… 이루면 보상 카드를 고르고
다음 숙원이 이어집니다. 상단에 진행도가 계속 보입니다.

여기에 **대가 끊길 위기**도 있습니다. 자손 없이 나이가 들면 미리 경고가 뜨고,
그대로 세상을 떠나면 이야기는 정말로 거기서 끝납니다.

## 자동으로 흐르는 시간

`▶ 자동으로 흘려보내기` 를 켜면 설정한 속도(🐢 6초 / 🚶 3.2초 / 🐇 1.5초마다 1년)로 시간이 흐릅니다.
버튼을 누르지 않아도 자녀와 배우자가 취업해 돈을 벌고, 마을이 수익을 내고, 아이들이 자랍니다.

**사건이 생기면 시간이 저절로 멈춥니다.** 이벤트·업적 보상·나비효과 알림 중 하나라도 뜨면
그것을 처리할 때까지 다음 해로 넘어가지 않습니다. 처리하면 다시 알아서 흐릅니다.

분가한 가족은 연봉의 20%를 집에 보태고, 아직 집에 있는 성인 자녀는 수입 전부가 살림에 들어옵니다.

## 인생 이벤트 84종 — 온 가족에게

매년 나이·직업·가족 관계에 맞는 이벤트 하나가 가중치에 따라 찾아옵니다.
**주인공만이 아니라 배우자·자녀·부모·형제·손주에게도 일어납니다.**
이벤트 창에는 그 사건의 주인공이 초상화와 호칭(아들·며느리·손녀…)으로 표시되고,
효과도 그 사람에게 적용됩니다. 나이 조건은 사건의 주인공을 기준으로 판정합니다.

| 시기 | 예시 |
|---|---|
| 유아 (0~4) | 첫 마디, 첫걸음, 밤울음, 첫 장난감 |
| 아동 (5~12) | 숨겨진 재능, 단짝, 돼지 저금통, 학예회, 괴롭힘 |
| 청소년 (13~18) | 첫사랑, 시험 전날, 밴드 결성, 사춘기, 졸업식 |
| 청년 (19~34) | 첫 월급, 독립, 부업, 번아웃, 마라톤 |
| 중년 (35~59) | 승진 경쟁, 부모님, 충동구매, 마을 대표 선거 |
| 노년 (60~) | 물려줄 것, 손주, 은퇴 후의 하루, 해보고 싶던 것 |
| 가족 | 결혼기념일, 말다툼, 아이의 꿈, 입학식, 배우자의 꿈 |

| 가족 구성원 | 형제자매 싸움, 어른의 한마디, 손주의 첫 등교, 명절, 가족 회의, 이사, 가족 여행, 동업 제안 |

여기에 **병맛 이벤트 15종**(🤪 표시)이 섞여 나옵니다.
비둘기와의 눈싸움, 밭에 착륙한 UFO, 닭이 사장이 된 회사, 하늘에서 쏟아진 고등어,
개가 마을 대표로 당선되는 일 같은 것들입니다. 웃기지만 보상은 진짜입니다.

선택지는 즉시 확정형과 **능력치 판정형**(성공률이 화면에 표시됨) 두 가지입니다.

## 🦋 나비효과 — 오늘의 선택이 훗날 돌아온다

선택지 중 일부에는 **🦋 훗날에 영향** 표시가 붙습니다. 그런 선택을 하면 그 결과가
바로 끝나지 않고 **3~18년 뒤에 다시 찾아옵니다.**

| 그때의 선택 | 몇 년 뒤 |
|---|---|
| 아이에게 악기를 배우게 함 | 그 아이가 무대에 서고, 마을이 다 보러 옵니다 |
| 시험 전날 놀러 나감 | 놓친 성적이 발목을 잡아 원하던 자리를 놓칩니다 |
| 번아웃을 버티며 일함 | 무리한 대가가 병원비로 돌아옵니다 |
| 건강검진 결과를 서랍에 넣음 | 그 결과지가 결국 구급차를 부릅니다 |
| 이웃을 기꺼이 도움 | 그 이웃이 크게 보답합니다 |
| 부모님의 부탁을 거절함 | 그 미안함이 오래 남습니다 |

**본인이 세상을 떠났으면 그 자손이 결과를 받습니다.** 인생 탭의 `🦋 씨앗이 된 선택` 에서
지금 자라고 있는 선택이 몇 년쯤 뒤에 돌아올지 볼 수 있습니다.

선택은 **흔적(flag)** 도 남깁니다. 음악·운동·책·사업·이웃·감자축제·UFO 같은 흔적이 쌓이면
그 흔적이 있어야만 열리는 **후속 사건**이 등장합니다 — 가문의 연주회, 2호점, 다시 온 손님,
감자의 날 10주년, 돌아온 인심.

## 선택의 결과가 보입니다

이벤트를 고르면 결과 화면에 **무엇이 얼마나 바뀌었는지** 배지로 뜹니다 —
`💸 비용 -800` `💰 자금 +2400` `😊 행복 +6` `🌱 흔적을 남김`.
판정 이벤트는 성공/실패가 표시되고, 주인공 카드의 능력치 옆에는 **지난해 대비 ▲▼**가 붙습니다.
나비효과와 꿈 달성 알림에도 같은 배지가 붙어, 무엇을 얻었는지 바로 알 수 있습니다.

## 업적과 보상 선택

업적 32종을 달성하면 그 자리에서 **보상 카드 3장** 중 하나를 고릅니다.
보상 종류는 12가지이고, 세대와 마을 규모에 따라 위력이 커집니다.

- 💰 축하금 / 🎰 무작위 자산
- 😊 가족 전체 기분 +20 / ❤️ 가족 전체 건강 +20 / 💞 배우자 애정 +30 / 🧒 자녀 잠재력 +8
- 📈 전 능력치 +8 / 🌿 수명 +6년 / ✨ 새로운 재능 각성 / 🎓 학업 점수 +50
- 🏗️ 건물 무료 증축 / 📣 마을 명성 +20

업적은 동·은·금 세 등급이며, 등급이 높을수록 강한 보상 후보가 나옵니다.
잠긴 업적은 진행도 막대로 얼마나 남았는지 보여줍니다.

## 족보 트리

가족 탭은 진짜 **족보 다이어그램**입니다. 세대가 위에서 아래로 놓이고, 부부는 💞로 나란히,
부모와 자식은 선으로 이어집니다. 세상을 떠난 사람도 흑백으로 남아 가문의 기록이 됩니다.
화면을 열면 주인공이 가운데 오도록 자동으로 맞춰지고, 옆으로 밀어 넓게 볼 수 있습니다.
인물을 누르면 능력치·특성·부모·자녀를 볼 수 있습니다.

## 게임의 심장: 유전

아이는 부모에게서 **외모 · 능력 · 성격**을 물려받습니다.

| 물려받는 것 | 방식 |
|---|---|
| 외모 (피부·머리색·머리모양·눈동자·얼굴형·주근깨) | 유전자마다 부모 중 한쪽에서 상속, 8% 확률로 돌연변이 |
| 능력 잠재력 | 부모 평균 ±10, 실제 능력치는 아기답게 낮게 시작해 자라며 잠재력에 수렴 |
| 성격·재능 | 부모의 특성 중 최대 2개 + 새로 나타나는 기질 (희귀 특성은 6%) |

화면의 얼굴은 이 유전자를 그대로 그린 SVG 초상화라, **아이가 누구를 닮았는지 눈으로 보입니다.**
머리 모양 11종을 뒷머리·앞머리 두 겹으로 그리고, 표정은 행복도에 따라 눈썹·입·기분 뱃지가 바뀝니다.
나이가 들면 머리가 하얘지고 주름이 생기며, 지능이 높으면 안경을 쓰고, 세상을 떠나면 눈을 감습니다.

```
index.html            화면 껍데기

server.mjs            의존성 없는 정적 서버
build.mjs             한 파일짜리 dist/play.html 생성기
src/
  core/
    rng.js            시드 기반 결정론적 난수 (저장/복원 가능)
    util.js           공용 상수와 도우미
    genetics.js       외모·능력·성격 유전
    person.js         인물 생성, 나이 먹기, 학력, 수명
    economy.js        연봉·생활비·승진
    village.js        건물 효과, 마을 등급, 관리비
    game.js           게임 상태와 흐름 (한 해 보내기, 이벤트, 나비효과, 결혼, 출산, 계승)
    achievements.js   업적 판정과 보상 지급
    life.js           꿈 · 위기 · 가문의 숙원
    save.js           localStorage 저장 / 클립보드 복사·붙여넣기
  data/
    names.js  traits.js  jobs.js  buildings.js  origins.js  dreams.js  crises.js  quests.js
    events.js         인생 이벤트 84종 (병맛 15종, 나비효과 28가지 포함)
    achievements.js   업적 32종과 보상 12종
  ui/
    avatar.js         유전자로 초상화 SVG 그리기 (표정·나이·기분 뱃지)
    tree.js           족보 트리 배치와 연결선 그리기
    effects.js        효과를 읽을 수 있는 배지로
    views.js          화면 조각 (문자열 HTML)
    app.js            상태 + 클릭 위임
tests/                node:test 기반 규칙 테스트
```

핵심 규칙(`src/core`)은 DOM을 전혀 모릅니다. 그래서 테스트에서 수백 년치 인생을 그냥 돌려볼 수 있습니다.

## 콘텐츠 추가하기

- **이벤트**: `src/data/events.js` 에 객체 하나를 더합니다. `check` 를 주면 능력치 판정 이벤트가,
  `tag: 'absurd'` 를 주면 병맛 이벤트가 됩니다. `minAge`/`maxAge` 는 **사건의 주인공** 기준입니다.
  `actor` 로 대상을 좁힐 수 있고(`'self'`/`'child'`/`'partner'`/`'elder'`, 기본은 가족 누구나),
  `needsJob`/`needsPartner`/`needsChild`/`needsSibling`/`needsGrandchild`/`requiresFlag` 로 조건을 겁니다.

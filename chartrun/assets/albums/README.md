# 앨범 사진

`a01.png` ~ `a16.png` 는 실제로 게임에 쓰이는 앨범 커버입니다.
17번(`레전드 명반`)만 아직 사진이 없어서 코드로 그린 무늬가 나옵니다.

## 사진 바꾸거나 더 넣기

1. 이미지를 이 폴더에 둡니다. 이름은 앨범 id 와 맞추는 게 편합니다 (`a17.png`).
2. `chartrun/src/data/albums.js` 에서 그 앨범의 `art` 를 그 경로로 씁니다.

   ```js
   album({
     id: 'a17',
     art: 'assets/albums/a17.png',   // null 이면 무늬로 그린다
     ...
   })
   ```

3. 끝입니다. 새로고침하면 그 앨범만 사진으로 바뀝니다.

## 알아두면 좋은 것

- 게임은 커버를 **20px 안팎**으로 그립니다. 원본이 크면 파일만 무거워지므로
  **48×48 정사각형**으로 줄여서 넣습니다 (지금 들어있는 것들이 그 크기입니다).
  줄일 때는 한 번에 확 줄이지 말고 절반씩 여러 번 줄여야 계단이 안 집니다.
- **단일 파일 빌드에도 자동으로 담깁니다.** `build.mjs` 가 `assets/albums/*.png`
  경로를 찾아서 `data:` URI 로 바꿔 넣습니다 — 따로 할 일이 없습니다.
- 파일을 못 찾으면 **조용히 원래 무늬로 돌아갑니다.** 게임은 안 깨지지만 눈으로는
  구별이 안 되므로, `tests/albums.test.js` 가 경로에 해당하는 파일이 실제로
  있는지 검사합니다.
- 사진을 넣어도 **행동·속도·체력은 그대로**입니다. 그림과 게임 규칙은 완전히
  분리돼 있습니다 (`src/render/albumArt.js` 가 그림만 담당).

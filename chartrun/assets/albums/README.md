# 앨범 사진 넣는 곳

지금 게임에 나오는 앨범 커버 17장은 전부 **코드로 그린 절차적 픽셀 무늬**입니다.
나중에 진짜 앨범 사진을 주시면, 여기에 파일만 넣고 데이터 한 줄만 고치면 바로 반영됩니다.

## 넣는 방법

1. 이미지 파일을 이 폴더에 둡니다. 이름은 앨범 id 와 맞추는 게 편합니다.

   ```
   chartrun/assets/albums/a01.png
   chartrun/assets/albums/a02.png
   ...
   ```

2. `chartrun/src/data/albums.js` 에서 그 앨범의 `art` 와 `name` 을 고칩니다.

   ```js
   album({
     id: 'a01',
     name: '데뷔 싱글',          // ← 진짜 이름으로
     title: '《안녕 나야》',       // ← 진짜 앨범명으로
     art: 'assets/albums/a01.png', // ← null 에서 이렇게 바꾸면 사진이 쓰인다
     ...
   })
   ```

3. 끝입니다. `npm start` 로 새로고침하면 그 앨범만 사진으로 바뀝니다.

## 알아두면 좋은 것

- **16×16 픽셀로 줄여서** 커버 자리에 그립니다. 원본은 정사각형이면 아무 크기나 괜찮지만,
  글씨가 많은 커버는 뭉개지니 색과 형태가 뚜렷한 사진이 잘 어울립니다.
- 파일을 못 찾거나 로딩에 실패하면 **조용히 원래 무늬로 돌아갑니다.** 게임이 깨지지 않습니다.
- 사진을 넣어도 **행동·속도·체력은 그대로**입니다. 그림과 게임 규칙은 완전히 분리돼 있습니다
  (`src/render/albumArt.js` 가 그림만 담당).
- 17장을 한꺼번에 안 바꿔도 됩니다. 바꾼 것만 사진, 나머지는 무늬로 섞여 나옵니다.
- 단일 파일 빌드(`npm run build:chart`) 로 만든 `dist/play.html` 은 이 폴더의 이미지를
  **포함하지 않습니다.** 사진까지 한 파일로 담고 싶으면 `art` 에 `data:image/png;base64,...`
  형태로 넣으면 됩니다.

| `b` | a02 | 리메이크 앨범 | `k` | a11 | 랩 믹스테잎 |

| `e` | a05 | 아이돌 컴백작 | `n` | a14 | 밀리언셀러 |
| `f` | a06 | 클럽 리믹스 | `o` | a15 | 트로트 대작 |

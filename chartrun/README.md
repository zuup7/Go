# 🎤 차트런 (Chart Run!)

**100위에서 시작해 1위까지 달린다.** 마리오처럼 달리고 뛰어서 음원차트 정상에 오르는
병맛 픽셀 플랫포머입니다. 앨범 17장이 길을 막고, 정상 직전에는 그 열일곱 장이
**하나로 합체해 최종 보스**가 됩니다.

이미지 파일도, 음원 파일도, 외부 라이브러리도 없습니다. 전부 코드로 그리고 코드로 냅니다.

## 실행하기

```bash
npm start              # http://localhost:5173/chartrun/ 에서 플레이
npm test               # 게임 규칙 테스트
npm run build:chart    # 서버 없이 열리는 chartrun/dist/play.html 한 파일 생성
```

> `index.html` 을 파일로 직접 열면 ES 모듈 때문에 동작하지 않습니다.
> 서버 없이 즐기려면 `npm run build:chart` 로 만든 한 파일을 여세요.

## 조작

| 키 | 하는 일 |
|---|---|
| `←` `→` / `A` `D` | 이동 |
| `Space` / `↑` / `W` | 점프 — **길게 누를수록 높이 뜬다** |
| `R` | 그 자리에서 다시 시작 |
| `Esc` / `P` | 일시정지 |
| `M` | 음소거 |

휴대폰에서는 화면 아래 버튼 세 개로 합니다.
발판을 살짝 벗어나도 잠깐은 점프가 되고(코요테 타임), 착지 직전에 누른 점프도
기억했다가 발동합니다(점프 버퍼). 그래서 마리오처럼 손에 붙습니다.

## 순위가 곧 진행도

화면 왼쪽 위의 **`#숫자`** 가 지금 순위입니다. 오른쪽으로 갈수록 숫자가 줄어듭니다.

| 스테이지 | 무대 | 순위 |
|---|---|---|
| 1 | 🎤 인디 신인의 거리 | 100위 → 50위 |
| 2 | 📺 음악방송 스튜디오 | 50위 → 20위 |
| 3 | 💾 스트리밍 서버 내부 | 20위 → 5위 |
| 4 | 🪜 차트 정상 계단 | 5위 → 2위 |
| 보스 | 👑 1위 앞 | 2위 → **1위** |

## 앨범 17장 — 아홉 가지 성격

밟으면 죽는 놈, 갈라지는 놈, 떨어지는 놈이 따로 있습니다.

| 행동 | 하는 짓 | 예시 |
|---|---|---|
| `walker` | 좌우 순찰, 낭떠러지에서 돌아섬 | 데뷔 싱글, 밀리언셀러 |
| `hopper` | 주기적으로 내 쪽으로 폴짝 | 리메이크 앨범, 트로트 대작 |
| `flyer` | 사인파로 공중을 떠다님 | 여름 시즌송, 새벽 자작곡 |
| `charger` | 같은 높이에 들어오면 돌진 | 아이돌 컴백작, 광고 삽입곡 |
| `shooter` | 음표 탄환을 쏨 | 감성 발라드, 랩 믹스테잎 |
| `spinner` | 회전하며 낭떠러지도 무시하고 달림 | 클럽 리믹스, 페스티벌 헤드라이너 |
| `dropper` | 머리 위에서 기다리다 떨어짐 | 조명 아래 라이브, 드라마 OST |
| `shielder` | **위에 가시** — 밟으면 내가 죽음 | 알고리즘 추천, 레전드 명반 |
| `splitter` | 밟으면 작은 앨범 둘로 갈라짐 | 컴필레이션 |

부딪히면 각자 병맛 대사를 던집니다. *"15초면 충분해"*, *"한 잔 하고 가"*, *"역사에 남는 건 나야"*.

**덤비기 전에는 반드시 예고가 있습니다.** 돌진형은 달려들기 전 눈썹을 번쩍이며 부르르 떨고,
낙하형도 떨어지기 직전에 흔들립니다. 예고 없이 들어오면 피할 방법이 없어서 트롤이 아니라
그냥 불합리한 게임이 됩니다. 또 모든 앨범은 **배치된 자리 근처에서만 순찰**합니다 —
안 그러면 벽을 만날 때까지 흘러가서 레벨 디자인이 통째로 무너집니다.

> 앨범 그림은 지금 전부 코드로 그린 무늬입니다.
> 진짜 사진으로 바꾸는 법은 [`assets/albums/README.md`](assets/albums/README.md) 에 있습니다.

## 트롤 함정 — 살짝 고양이마리오

보스전 전까지는 정직한 길이 아닙니다. 다만 **목숨은 무한**이고,
**한 번 당한 함정은 그 뒤로 화면에 붉게 표시**돼서 외우면 반드시 넘어갑니다.

- **가짜 발판** — 밟는 순간 사라진다. 하필 그 위에 음표가 놓여 있다.
- **낙하 앨범** — 아래를 지나가면 머리 위에서 떨어진다.
- **역주행 바닥** — 올라서면 왼쪽으로 밀린다.
- **낚시 블록** — `?` 인 줄 알고 쳤더니 리믹스가 튀어나온다.
- **투명 블록** — 안 보이는 벽이 점프 궤도를 막는다.
- **불쑥 가시** — 평범한 땅인 척하다가 지나가면 솟는다.
- **도망가는 골** — 다가가면 달아난다. 진짜 깃발은 따로 있다.

죽으면 *"음원 사재기 의혹으로 차트아웃"*, *"립싱크가 걸렸다"* 같은 문구가 뜨고
**차트아웃 횟수**가 하나 올라갑니다. 이 숫자는 엔딩까지 따라와서 자랑거리가 됩니다.

## 합체 컷신과 최종 보스

스테이지 4를 통과하면 컷신이 시작됩니다. 열일곱 장이 화면 중앙으로 빨려 들어가
소용돌이치다 하나로 뭉치고, **《초합체 정규앨범 — 명반 名盤》** 이 등장합니다.

보스전은 체력에 따라 세 페이즈로 넘어갑니다. 페이즈는 절대 뒤로 가지 않습니다.

1. **회전 · 음표 탄막** — 부채꼴로 탄을 뿌립니다. 주기적으로 가운데 **재생 버튼**이
   초록으로 열리는데, 그때만 밟을 수 있습니다.
2. **분열 · 4중 돌진** — 네 조각으로 갈라져 화면을 가로지릅니다. 탄도 빨라집니다.
3. **사재기 · 총력전** — 잡몹 앨범을 계속 소환하며 패턴이 가장 빨라집니다.

쓰러뜨리면 **#1** 엔딩 화면에서 걸린 시간, 차트아웃 횟수, 물리친 앨범 수,
모은 재생수를 정리해 보여줍니다.

## 어떻게 만들어졌나

```
chartrun/
  index.html            캔버스 + 터치 버튼
  assets/style.css      픽셀 렌더링, CRT 스캔라인, 모바일 대응
  assets/albums/        ★ 나중에 앨범 사진 넣는 곳
  src/core/             게임 규칙 — DOM 을 절대 쓰지 않는다
    physics.js          AABB 타일 충돌, 코요테 타임, 점프 버퍼
    world.js            타일맵 파서
    player.js  enemy.js  boss.js  chart.js  game.js
    audio.js            WebAudio 로 만드는 칩튠 (오디오 파일 0개)
    save.js  camera.js  loop.js  input.js  rng.js
  src/data/             앨범 17종 · 스테이지 4개 · 함정 · 컷신 · 보스 수치
  src/render/           캔버스 그리기 (한글은 DOM 이 맡는다)
    pixel.js            문자열 스프라이트 → 캔버스로 굽기
    albumArt.js         ★ 절차적 커버 + 사진 교체 훅
    sprites.js  scene.js  hud.js
  tests/                node --test 로 도는 규칙 테스트
```

**핵심 규칙: `core/` 와 `data/` 는 캔버스도 DOM 도 import 하지 않습니다.**
그래서 물리·적 행동·보스 페이즈·레벨 구조를 브라우저 없이 그대로 테스트할 수 있습니다.

논리는 고정 60Hz 로 돌고(`loop.js`), 그리기만 화면 주사율을 따릅니다.
내부 해상도는 384×224 이고 정수배로만 확대해서 픽셀이 뭉개지지 않습니다.

### 레벨 고치기

`src/data/stages.js` 는 **20칸 × 14줄짜리 구간(chunk)** 을 옆으로 이어 붙여 스테이지를 만듭니다.
눈으로 보고 고칠 수 있고, 줄 수나 칸 수가 틀리면 불러올 때 바로 알려줍니다.

```
' ' 빈 칸      '#' 땅          '=' 관통 발판     '?' 아이템 블록
'X' 낚시 블록  'I' 투명 블록   '%' 가짜 발판     '~' 역주행 바닥
'^' 가시       'v' 불쑥 가시   '*' 재생수(음표)  'S' 시작
'C' 체크포인트 'G' 골          'F' 도망가는 가짜 골
'a'~'q' 앨범 17종
```

테스트가 스테이지마다 시작점·골·체크포인트가 있는지, 쓴 앨범 글자가 실제로 존재하는지,
구멍이 한 번에 건널 수 있는 폭인지(넓다면 위에 딛을 발판이 있는지)를 검사합니다.

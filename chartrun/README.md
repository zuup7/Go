# 🎤 차트런 (Chart Run!)

**100위에서 시작해 1위까지 달린다.** 마리오처럼 달리고 뛰어서 음원차트 정상에 오르는
픽셀 플랫포머입니다. 앨범 17장이 길을 막고, 정상 직전에는 그 열일곱 장이
**하나로 합체해 최종 보스**가 됩니다.

이미지 파일도, 음원 파일도, 외부 라이브러리도 없습니다. 전부 코드로 그리고 코드로 냅니다.

**화면에 나오는 글자는 숫자뿐입니다.** 순위·재생수·차트아웃 횟수·시간·스테이지 번호.
대사도, 사망 문구도, 스테이지 이름도 없습니다 — 무슨 일이 벌어지는지는 화면이 말합니다.

## 실행하기

```bash
npm start              # http://localhost:5173/chartrun/ 에서 플레이
npm test               # 게임 규칙 테스트
npm run build:chart    # 서버 없이 열리는 chartrun/dist/play.html 한 파일 생성
```

> `index.html` 을 파일로 직접 열면 ES 모듈 때문에 동작하지 않습니다.
> 서버 없이 즐기려면 `npm run build:chart` 로 만든 한 파일을 여세요.

### 개발자 모드 — 스테이지 골라 들어가기

평소에는 **1스테이지부터 쭉** 깹니다. 보스전만 다시 보고 싶을 때 초원부터 다시 달리기는
번거로우니, 타이틀 구석의 **⚙** 를 누르고 **1234** 를 넣으면 스테이지 선택이 열립니다.
숨기려고 만든 게 아니라 실수로 눌리지 않게 하려고 만든 것이라 암호랄 것도 없습니다.

- 스테이지 넷 + 보스전을 바로 고를 수 있고, 🎬 오프닝도 다시 볼 수 있습니다.
  마지막 칸에서 개발자 모드를 다시 끕니다.
- **골라 들어간 판은 기록을 갱신하지 않습니다.** 보스만 골라 이기고 최고 기록이 되면
  기록이 거짓말이 됩니다. 죽은 횟수만 그대로 쌓입니다.
- 3스테이지로 들어가면 순위도 그 자리(#20)에서 시작합니다.

### 휴대폰 — 가로로 꽉 차게

폰에서는 **게임이 화면을 꽉 채웁니다.** 조작 버튼은 화면 아래에 자리를 따로 차지하지 않고
좌우 검은 여백과 화면 구석에 반투명으로 겹쳐 뜹니다 — 아래에 버튼 줄을 깔면 정작 게임이
손톱만 해집니다. 보스전에서는 🎤 던지기 버튼이 하나 더 나옵니다.

**세로로 들고 있으면 화면을 통째로 눕힙니다.** 회전 잠금을 켜둔 사람이 많아서
"가로로 돌려주세요" 라고만 써두면 아무 일도 일어나지 않기 때문입니다. 폰을 옆으로 돌려 잡으면
그때부터 똑바로 보입니다.

버튼 위에서 **엄지를 미끄러뜨려도 됩니다.** ◀ 에서 ▶ 로 밀면 그대로 방향이 바뀝니다
(누른 채로 미끄러뜨리면 이전 버튼이 눌린 채 남는 게 흔한 버그입니다).

### 버튼 자리와 크기는 직접 정합니다

손 크기도 잡는 법도 사람마다 다릅니다. 화면 구석의 **✥** 를 누르면 편집 모드가 되고,
버튼을 **끌어다 원하는 자리에 놓으면** 됩니다. 같은 편집 바의 **− / +** 로
**크기도 70%~180%** 까지 바꿉니다. 기기에 저장돼서 다음에도 그대로입니다.
`처음대로` 로 되돌릴 수 있습니다.

크기를 키우면 가장자리에 붙여둔 버튼이 자동으로 안쪽으로 밀려 들어옵니다 —
화면 밖으로 삐져나가면 아예 누를 수가 없기 때문입니다.
크기는 슬라이더가 아니라 버튼입니다. 눕힌 화면은 90도 돌아가 있어서 끌기 좌표가 틀어집니다.

- 편집하는 동안에는 **게임이 멈춥니다** — 옮기다가 죽으면 억울합니다.
- 자리는 픽셀이 아니라 **비율**로 저장해서, 화면 크기가 달라져도 같은 자리에 남습니다.
- **가로로 든 것과 세로로 눕힌 것은 따로 기억합니다.** 좌표계가 90도 틀어져 있어서
  한쪽에서 잡은 자리를 다른 쪽에 그대로 쓰면 엉뚱한 데로 갑니다.
- 앱이 화면 위아래에 얹는 것들(아티팩트 뷰어의 닫기 X, 안드로이드 내비게이션 바) 밑으로는
  **아예 못 옮깁니다.** 거기 두면 눌리지도 않고, 누르려다 게임이 닫힙니다.

### 손에 붙는 이유

| 장치 | 하는 일 |
|---|---|
| 코요테 타임 | 발판을 살짝 벗어나도 6프레임 동안은 점프가 된다 |
| 점프 버퍼 | 착지 직전에 누른 점프를 8프레임 기억했다 발동한다 |
| **모서리 보정** | 머리 귀퉁이가 블록에 5px 이하로 스치면 옆으로 밀어 통과시킨다 |
| **정점 체공** | 점프 꼭대기 근처에서 중력이 약해져 겨눌 틈이 생긴다 |
| **빠른 낙하** | 내려올 때는 중력이 1.45배 — 붕 뜨는 느낌이 사라진다 |
| **방향 전환 가속** | 가던 방향의 반대를 누르면 2.1배로 꺾인다 |

이 숫자들을 만지면 레벨이 조용히 못 깨는 판이 될 수 있어서, **달리며 뛰면 세 칸 구멍을 넘고
두 줄을 오른다**는 것을 테스트가 직접 시뮬레이션해서 확인합니다.

## 오프닝 — 왜 달리는가

처음 시작하면 **12초짜리 오프닝**이 뜹니다. 대사는 없습니다.

좁은 방, 책상 위 마이크 하나, 그리고 **옆에 앉은 강아지 공주.**
음표가 하나 떠오르고, 위로 빨려 올라갑니다.
차트 순위표가 내려오고 — 맨 아래 **`#100`** 칸에 내가 걸립니다.
위를 훑어보면 앨범들이 끝없이 쌓여 있고, 하나같이 나를 내려다봅니다.
그중 하나가 방까지 내려와 **그녀를 채갑니다.** 뛰어올라 손을 뻗지만 놓칩니다.
마이크를 쥐고 달려나갑니다.

### 그래서 1위로 가는 길이 곧 그녀를 되찾는 길입니다

납치가 이야기를 끝까지 꿰맵니다. 안 그러면 마지막에 처음 보는 강아지와 갑자기 결혼합니다.

| 어디 | 그녀는 |
|---|---|
| 오프닝 | 앨범이 채간다 |
| 합체 컷신 | 소용돌이에 같이 휘말리고, 합쳐진 원반 위에 새장이 얹힌다 |
| 보스전 | 싸우는 내내 보스 머리 위에 갇혀 있다 |
| 엔딩 | 보스가 터질 때 새장이 부서지고 풀려난다 → 결혼식 |

**격파가 곧 구출**이라는 규칙은 `princessCaged(boss)` 한 곳에만 있습니다
(`src/core/boss.js`). 그리는 쪽은 상태를 따로 안 들고 이걸 물어봅니다.

- **한 번만 뜹니다.** 그 다음부터는 예전처럼 곧장 스테이지 1 입니다
  (`save.seenOpening`). 언제든 건너뛸 수 있습니다.
- 다시 보려면 **개발자 모드 → 🎬 오프닝 다시 보기**.
- 마지막에 스테이지 브금으로 갈아타므로, 스테이지 1 이 시작될 때 음악이 이미 흐릅니다.

## 순위가 곧 진행도

화면 왼쪽 위의 **`#숫자`** 가 지금 순위입니다. 오른쪽으로 갈수록 숫자가 줄어듭니다.

| 스테이지 | 무대 | 순위 |
|---|---|---|
| 🌿 STAGE 1 | 초원 — 언덕과 구름, 들꽃 | 100위 → 50위 |
| 🌳 STAGE 2 | 숲 — 나무 줄기 사이로 빛줄기 | 50위 → 20위 |
| 🏢 STAGE 3 | 건물 안 — 창문 격자와 기둥, 형광등 | 20위 → 5위 |
| 🪜 STAGE 4 | 차트 정상 계단 | 5위 → 2위 |
| 👑 BOSS | 1위 앞 | 2위 → **1위** |

무대 그림은 `stage.theme` 이 고르고 색은 `stage.sky / far / ground` 에서 옵니다
(`src/render/scene.js`). 둘이 나뉘어 있어서 같은 무대를 낮/밤으로 바꾸는 것도 색만 갈면 됩니다.

## 앨범 17장 — 아홉 가지 성격

밟으면 죽는 놈, 갈라지는 놈, 떨어지는 놈이 따로 있습니다.

| 행동 | 하는 짓 | 예시 |
|---|---|---|
| `walker` | 좌우 순찰, 낭떠러지에서 돌아섬 | 데뷔 싱글, 밀리언셀러 |
| `hopper` | 주기적으로 내 쪽으로 폴짝 | 리메이크 앨범, 트로트 대작 |
| `flyer` | 사인파로 공중을 떠다님 | 여름 시즌송, 새벽 자작곡 |
| `charger` | 같은 높이에 들어오면 돌진 | 아이돌 컴백작, 광고 삽입곡 |
| `shooter` | 음표 탄환을 쏨 | 감성 발라드, 랩 믹스테잎 |
| `spinner` | 회전하며 낭떠러지도 무시하고 달림 | 클럽 리믹스, 페스티벌 헤드라이너 |
| `dropper` | 머리 위에서 기다리다 떨어짐 | 조명 아래 라이브, 드라마 OST |
| `shielder` | **위에 가시** — 밟으면 내가 죽음 | 알고리즘 추천, 레전드 명반 |
| `splitter` | 밟으면 작은 앨범 둘로 갈라짐 | 컴필레이션 |

**덤비기 전에는 반드시 예고가 있습니다.** 돌진형은 달려들기 전 눈썹을 번쩍이며 부르르 떨고,
낙하형도 떨어지기 직전에 흔들립니다. 사격형도 쏘기 직전 **멈춰 서서 눈썹을 번쩍입니다** —
탄이 날아오고 나서야 알면 피할 방법이 없습니다. 예고 없이 들어오면 피할 방법이 없어서 트롤이 아니라
그냥 불합리한 게임이 됩니다. 또 모든 앨범은 **배치된 자리 근처에서만 순찰**합니다 —
안 그러면 벽을 만날 때까지 흘러가서 레벨 디자인이 통째로 무너집니다.

> 앨범 커버는 **진짜 사진 16장**입니다 (`assets/albums/`). 17번만 아직 사진이 없어서
> 코드로 그린 무늬가 나옵니다. 바꾸거나 더 넣는 법은
> [`assets/albums/README.md`](assets/albums/README.md) 에 있습니다.

## 트롤 함정 — 살짝 고양이마리오

보스전 전까지는 정직한 길이 아닙니다. 다만 **목숨은 무한**이고,
**한 번 당한 함정은 그 뒤로 화면에 붉게 표시**돼서 외우면 반드시 넘어갑니다.

- **가짜 발판** — 밟는 순간 사라진다. 하필 그 위에 음표가 놓여 있다.
- **낙하 앨범** — 아래를 지나가면 머리 위에서 떨어진다.
- **역주행 바닥** — 올라서면 왼쪽으로 밀린다.
- **낚시 블록** — `?` 인 줄 알고 쳤더니 리믹스가 튀어나온다.
- **투명 블록** — 안 보이는 벽이 점프 궤도를 막는다.
- **불쑥 가시** — 평범한 땅인 척하다가 지나가면 솟는다.
- **도망가는 골** — 다가가면 달아난다. 진짜 깃발은 따로 있다.
- **무너지는 바닥** — 멀쩡한 땅인 척하다 올라서면 부르르 떨다 꺼진다. 멈추면 떨어진다.
- **솟아오르는 벽** — 달리다 보면 앞에서 벽이 쿵 하고 솟는다. 두 칸이라 넘을 수는 있다.
- **역재생 구간** — 4초간 **좌우가 뒤바뀐다.** 차트 게임다운 트롤.
- **정전** — 스트리밍 서버가 나가고 3.5초간 내 주변만 빼고 깜깜해진다.

죽으면 **차트아웃 횟수**가 하나 올라갑니다. 이 숫자는 엔딩까지 따라와서 자랑거리가 됩니다.

## 합체 컷신과 최종 보스

스테이지 4를 통과하면 컷신이 시작됩니다. 열일곱 장이 화면 중앙으로 빨려 들어가
소용돌이치다 하나로 뭉치고, 보스가 등장합니다. **컷신에 대사는 없습니다.**

**보스를 때리는 두 가지 방법**

- 🎤 **던지기** — 보스가 주기적으로 마이크를 흘립니다. 주워서 `X` 로 던지면 멀리서 안전하게 한 대.
  **한 번 쓰면 없어지므로** 다음 드롭까지 기다려야 합니다.
- 👟 **밟기** — 가운데 **재생 버튼**이 초록으로 열릴 때만 밟을 수 있습니다. 붙어야 해서 위험하지만
  마이크를 기다릴 필요가 없습니다.

체력은 **9** — 페이즈당 세 대입니다. 체력계는 보스 바로 아래에 붙어 다녀서 화면을 가리지 않습니다.

보스전은 체력에 따라 세 페이즈로 넘어갑니다. 페이즈는 절대 뒤로 가지 않고, 바뀔 때마다
**전환 컷신**이 끼어듭니다. 컷신이 도는 동안에는 보스도 탄도 나도 완전히 멈추므로
연출 보다가 맞아 죽는 일은 없습니다. 확인 키로 건너뛸 수 있습니다.

1. 부채꼴로 탄을 뿌립니다. 주기적으로 가운데 **재생 버튼**이 초록으로 열리는데,
   그때만 밟을 수 있습니다.
2. 네 조각으로 갈라져 화면을 가로지릅니다. 탄도 빨라집니다.
3. 잡몹 앨범을 계속 소환하며 패턴이 가장 빨라집니다.

**전환 컷신**
1. **페이즈 2** — 보스가 부르르 떨다 금이 가고 네 조각으로 쪼개진다
2. **페이즈 3** — 가짜 실시간 차트가 뜨고, 꼴찌였던 보스가 대놓고 1위로 솟는다.
   그리고 그 힘으로 **합체한다** — 2페이즈에서 쪼개졌던 조각이 사방에서 불려와
   팔·다리·머리가 차례로 붙고, 가슴 코어에 불이 들어온다.
   조작이 합체의 **이유**라 순서가 정해져 있다 (`rig` → `call` → `assemble` → `core`).

   합체한 뒤로는 원반이 아니라 로봇으로 싸운다. 궤도를 도는 조각도 파편이 아니라
   **로켓 펀치**로 바뀐다 — 합쳐놓고 파편이 날아다니면 앞뒤가 안 맞는다.
   약점은 그대로 가운데 재생 버튼이고, 로봇에서는 가슴 코어가 된다.
   원반으로 그릴지 로봇으로 그릴지는 `bossCombined(boss)` 하나가 정한다
   (`src/core/boss.js`) — 페이즈는 뒤로 안 가므로 한 번 합체하면 안 풀린다.

쓰러뜨리면 **엔딩 컷신**이 이어집니다. 18초, 2부로 나뉩니다.

**1부 — 1위** 보스가 터지며 앨범 열일곱 장이 사방으로 흩어지고, 그 중 다섯 장이 2위부터
아래로 줄을 섭니다. 맨 윗줄만 비어 있고, 거기에 내가 올라서면 **#1** 이 박힙니다.

**2부 — 결혼식** 차트 순위표가 그대로 식장이 됩니다. 줄 서 있던 앨범 열일곱 장이 하객이 되어
붉은 카펫 양옆에 앉고, 1위 자리에는 꽃 아치가 섭니다. **연갈색 말티푸 강아지 공주**가
카펫을 따라 걸어 들어와 왕관 쓴 나와 마주 서고, 둘 사이로 반지가 떠오르고, 하트와 축포로 끝납니다.

그 다음 통계 화면에서 걸린 시간, 차트아웃 횟수, 물리친 앨범 수, 찾은 함정 수, 모은 재생수를
보여줍니다. 최고 기록을 깼으면 시간 옆에 **신기록**이 붙습니다 — 표시와 저장이 어긋나지 않게
`beatRecord()` 한 함수가 둘 다 판단합니다. 타이틀에도 `BEST #순위 · 최고 기록`이 뜹니다.
컷신은 언제든 건너뛸 수 있습니다.

### 컷신에도 소리가 붙습니다

터지고, 줄 서고, 반지가 떠오르는 순간마다 소리가 납니다. 결혼식이 시작되면
**웨딩 마치**로 갈아탑니다 — 느리고, 킥도 하이햇도 없습니다 (칩튠 특유의 치찰음이
들어가면 식장이 아니라 던전이 됩니다).

**언제 울릴지를 소리 쪽에 다시 적지 않습니다.** 시각은 타임라인 한 곳에만 있고,
게임이 단계를 넘어가는 순간 `cutbeat` 으로 알려주면 소리 쪽은 그것만 받습니다
(`data/cutSound.js` 가 단계 → 소리 표). 타임라인을 고치면 소리도 따라옵니다.
표에 빠진 단계가 있으면 테스트가 잡습니다.

## 어떻게 만들어졌나

```
chartrun/
```

**핵심 규칙: `core/` 와 `data/` 는 캔버스도 DOM 도 import 하지 않습니다.**
그래서 물리·적 행동·보스 페이즈·레벨 구조를 브라우저 없이 그대로 테스트할 수 있습니다.

논리는 고정 60Hz 로 돌고(`loop.js`), 그리기만 화면 주사율을 따릅니다.
내부 해상도는 384×224 이고 정수배로만 확대해서 픽셀이 뭉개지지 않습니다.

### 레벨 고치기

`src/data/stages.js` 는 **20칸 × 14줄짜리 구간(chunk)** 을 옆으로 이어 붙여 스테이지를 만듭니다.
눈으로 보고 고칠 수 있고, 줄 수나 칸 수가 틀리면 불러올 때 바로 알려줍니다.

```
' ' 빈 칸      '#' 땅          '=' 관통 발판     '?' 아이템 블록
'X' 낚시 블록  'I' 투명 블록   '%' 가짜 발판     '~' 역주행 바닥
'^' 가시       'v' 불쑥 가시   '*' 재생수(음표)  'S' 시작
',' 무너지는 바닥  '|' 솟아오르는 벽  'R' 역재생 구간  '@' 정전 구간
'C' 체크포인트 'G' 골          'F' 도망가는 가짜 골
'a'~'q' 앨범 17종
```

테스트가 다음을 검사합니다: 스테이지마다 시작점·골·체크포인트가 있는지, 쓴 앨범 글자가 실제로
존재하는지, 구멍이 한 번에 건널 수 있는 폭인지(넓다면 위에 딛을 발판이 있는지),
**솟는 벽 위가 막혀 있지 않은지**(막히면 길이 영영 끊긴다), **구간 트리거가 밟을 수 있는 자리인지**,
그리고 **역재생·정전이 반드시 저절로 풀리는지**(영구히 걸리면 게임이 끝난다).

컷신도 같은 식으로 못 박아 뒀습니다: 세 컷신이 **반드시 저절로 풀리고**(안 풀리면 게임이 영영 멈춘다),
도는 동안 **체력도 플레이어도 안 움직이고**, 건너뛰기가 먹고, 격파하면 엔딩 컷신을 거쳐
통계가 그대로 넘어옵니다.
